# AI Engineering

A project-driven roadmap documenting my journey toward becoming an AI Engineer.

Rather than following isolated tutorials, this repository is organized as a sequence of progressively more challenging projects. Each project focuses on a specific concept used in modern AI systems and builds upon previous work.

The goal is to develop a deep understanding of how production AI applications are designed, implemented, and deployed by building everything from scratch.

---

## Goals

- Develop a strong understanding of Large Language Models (LLMs)
- Build production-quality AI applications from first principles
- Learn modern AI engineering practices through hands-on projects
- Understand not only how to use AI tools, but how they work internally
- Create a portfolio that demonstrates practical AI engineering skills

---

## Learning Philosophy

This repository emphasizes:

- Project-based learning
- Building before using frameworks
- Understanding system design and architecture
- Writing clean, maintainable code
- Learning production engineering practices rather than toy examples

Whenever possible, projects are implemented without high-level frameworks first. Once the underlying concepts are understood, production frameworks are introduced later to compare abstractions against manual implementations.

---

## Repository Structure

Each project lives in its own directory and includes:

- Source code
- README explaining the project
- Lessons learned
- Concepts covered

Projects are organized in the order they were completed.

Example:

```
00-Example Project/
    README.md
    project.py

10-Another Project/
    README.md
    project.py
```
